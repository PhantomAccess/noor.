# Noor.

A minimalist dark-mode Muslim companion web app.

### Features
- Clean Quran reader (Surah list + reading view)
- Accurate Qiblah finder using device sensors + GPS
- Prayer times with multiple calculation methods
- Gregorian + Hijri dates
- Daily Quranic reminder
- English & Bahasa Melayu support
- Fully responsive, works on mobile browsers
